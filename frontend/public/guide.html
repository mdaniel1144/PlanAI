Habitat quick guide

Create a project, create a floor, and use the canvas toolbar to draw walls that automatically define Spaces. Open Tool settings for wall dimensions and opening details.

Finish drawing

Double-click to finish a wall chain. Spaces appear automatically. Select a Space to set its name, type, floor elevation, and ceiling elevation. Dashed edges represent open boundaries, not walls. Advanced geometry offers explicit manual boundaries when needed.

View and properties

View contains grid, snapping, labels, floor selection, and editor status. Select an element to edit its properties. Switch between 2D, 3D, and Split to inspect the same geometry.

Save and export

Save changes in the header updates the current scene. Undo and Redo apply to local edits until saving. Export downloads the current scene as JSON.

Keyboard

V Select · H Pan · W Wall · D Door · M Measure · Esc Stop drawing · Ctrl/Cmd+S Save
